# پروژه فروشگاه اینترنتی | Online Shop API

## معرفی پروژه

این پروژه یک API فروشگاه اینترنتی است که با استفاده از Django و Django REST Framework توسعه داده می‌شود.

هدف از ساخت این پروژه، پیاده‌سازی یک Backend کاربردی با تمرکز بر طراحی اصولی دیتابیس، مدیریت کاربران و محصولات، پردازش سفارش‌ها، بهینه‌سازی عملکرد و تست‌نویسی است.

## تکنولوژی‌های استفاده‌شده

- Python
- Django
- Django REST Framework
- PostgreSQL
- Redis
- Simple JWT
- Pytest
- Git

## قابلیت‌های پروژه

### ۱. مدیریت کاربران و احراز هویت
- ثبت‌نام کاربران
- ورود کاربران با استفاده از JWT
- مدیریت Access Token و Refresh Token
- مدیریت سطح دسترسی کاربران

### ۲. مدیریت محصولات و دسته‌بندی‌ها
- ایجاد، ویرایش، مشاهده و حذف محصولات
- مدیریت دسته‌بندی محصولات
- پشتیبانی از چند تصویر برای هر محصول
- تعیین خودکار تصویر اصلی محصول
- مدیریت ترتیب نمایش تصاویر
- مدیریت موجودی محصولات
- فعال و غیرفعال کردن محصولات

### ۳. جست‌وجو و فیلتر محصولات
- جست‌وجوی محصولات
- فیلتر بر اساس دسته‌بندی و قیمت
- مرتب‌سازی محصولات
- صفحه‌بندی نتایج (Pagination)

### ۴. سبد خرید (Shopping Cart)
- افزودن محصول به سبد خرید
- حذف محصولات از سبد خرید
- تغییر تعداد محصولات
- محاسبه مبلغ نهایی سبد خرید
- بررسی موجودی محصولات

### ۵. مدیریت سفارش‌ها (Order Management)
- ثبت سفارش توسط کاربران
- مشاهده تاریخچه سفارش‌ها
- مدیریت وضعیت سفارش‌ها
- کنترل موجودی هنگام ثبت سفارش
- استفاده از Database Transactions برای حفظ یکپارچگی اطلاعات

### ۶. بهینه‌سازی و مدیریت کش
- استفاده از Redis برای ذخیره اطلاعات پرتکرار
- پیاده‌سازی Cache Invalidation
- استفاده از Django Signals برای مدیریت تغییرات مدل‌ها
- بهینه‌سازی Queryهای دیتابیس با استفاده از `select_related` و `prefetch_related`

### ۷. تست‌نویسی (Testing)
- تست مدل‌ها و منطق برنامه
- تست APIها
- تست احراز هویت و سطح دسترسی
- تست سبد خرید و سفارش‌ها
- بررسی سناریوهای خطا و شرایط غیرعادی

### ۸. مستندسازی و راه‌اندازی
- مستندسازی API با Swagger / OpenAPI
- مدیریت تنظیمات با Environment Variables
- راه‌اندازی پروژه با Docker
- مستندسازی مراحل نصب و اجرای پروژه
